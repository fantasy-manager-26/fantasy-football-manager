# Fantasy Football Manager

Fantasy Football Manager is a personal, non-commercial project for analyzing and managing a single user's fantasy football team.

## Purpose

The project is designed to provide data-driven fantasy football analysis and decision support using the user's actual league configuration and team context.

## Yahoo Fantasy Sports API Usage

The project will use read-only access to the Yahoo Fantasy Sports API to retrieve data associated with the user's own fantasy football league, including:

- League settings and scoring rules
- Team roster and lineup
- League teams and standings
- Weekly matchups
- Player information
- Transactions
- Available players and free agents

The retrieved data will be used for roster analysis, start/sit decisions, waiver and add/drop analysis, trade evaluation, matchup analysis, and weekly fantasy football management recommendations.

## Intended Users

This is a personal, single-user project intended only for the owner's own fantasy football league. It is not a commercial service and will not redistribute Yahoo Fantasy Sports data to the public.

## Access

Read-only API access is sufficient for the current project. The project does not require write access to Yahoo Fantasy Sports.
